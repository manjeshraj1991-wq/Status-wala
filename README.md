# Status Wala (स्टेटस वाला) 🌟

Minimalist daily affirmations, Hindi/Indian status quotes customization, Bollywood & regional movie dialogues/video status, end-to-end encrypted journaling, mood tracking, and mindfulness soundscapes.

## Features
- **Daily Affirmations & Status**: Beautiful card generator for WhatsApp, Instagram Stories, and Facebook.
- **Movie Dialogues & Songs**: Curated movie status clips and dialogues with audio player.
- **Mood Tracker**: Log your mood and discover mood-aligned affirmations.
- **Zero-Knowledge Encrypted Journal**: Client-side AES-256 encrypted private notes.
- **Mindfulness Soundscapes**: Offline audio synthesizer for calm and meditation.
- **Multilingual Support**: Hindi, English, Bengali, Punjabi, Gujarati, Tamil, Telugu, Marathi, and more.

## 🚀 How to Run Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel (100% Free Lifetime Hosting)

1. Create a free account at [vercel.com](https://vercel.com) using your GitHub account.
2. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Deploy Status Wala"
   git branch -M main
   git remote add origin https://github.com/<your-username>/status-wala.git
   git push -u origin main
   ```
3. In Vercel, click **Add New... > Project** and select `status-wala`.
4. Click **Deploy**. Vercel will build and give you a free live URL (e.g., `https://status-wala.vercel.app`)!
